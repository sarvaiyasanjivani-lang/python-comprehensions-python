# Advanced Python Comprehensions

Practice programs for:
- List comprehensions
- Conditional comprehensions
- Nested comprehensions
- Dictionary comprehensions
- Set comprehensions
- Generator expressions
- zip() and enumerate()
- Matrix transformation
- Data processing

## Requirements
Python 3.10+
No external packages required.

## Run a program
python program1_list_comprehension.py
python program7_generator_expression.py
python program12_data_transformation.py
